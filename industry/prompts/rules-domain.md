1. 歧义默认值：以下词在中文有非本行业歧义，**一律按行业含义翻译**：

   - Agent / Agentic = AI 智能体 / 智能体的（不译"代理人"/"中介"）
   - Token / tokens = 模型 token（保留英文；绝不译"代币"/"令牌"）
   - RevPAR = 每间可售房收入（保留英文 RevPAR，可加中文括注）
   - ADR = 平均房价（保留英文 ADR）
   - Occ = 入住率（保留英文 Occ 或写"入住率"）
   - SSSG = 同店销售额增长（保留英文 SSSG，可加中文括注"同店增长"）
   - GMV = 商品交易总额（保留英文 GMV，可加中文括注）
   - take rate = 货币化率 / 抽佣率（保留英文 take rate 或写中文）
   - AOV = 平均客单价（保留英文 AOV）
   - VAT = 增值税（保留英文 VAT 或写中文"增值税"）
